# 宽基与核心配置说明

> 本系统采用 **核心-卫星** 策略：用「真宽基」打底降波动，用「行业卫星」博超额，用「海外 QDII」分散。  
> 配置见 `config/strategy.yaml` → `core_satellite` / `portfolio_plan` / `fund_universe.csv`。

---

## 一、什么是宽基？

**宽基指数基金**跟踪覆盖**整个市场或大盘**的指数，一次买入众多行业龙头，用来：

- **打底**：降低单押一个行业的风险  
- **跟经济走**：长期分享 A 股整体或核心资产收益  
- **少折腾**：费率低、规则透明，适合长期持有  

**不是宽基**的例子：只跟踪「创新药」「人工智能」「500 信息技术」等**单一行业/主题**的基金——波动更大，应放在「卫星」层。

### 沪深300 vs 中证A500 怎么选？

公开资料与机构观点大致归纳（不构成投资建议）：

- **求稳、当压舱石** → 偏重 **沪深300**（110020）  
- **求均衡、要一点成长弹性** → 偏重 **中证A500**（022430）  
- **不必二选一** → 本系统默认 **50% : 50%** 分配新增资金（`primary_core_split`）

参考：[4000点看宽基！沪深300 VS A500怎么选？](https://app-web.chnfund.com/YHHEediting/202511/t20251110_4576080.html)

```
┌─────────────────────────────────────────────────────────┐
│  管理仓（参与再平衡）                                      │
│  ├─ 宽基 60%：110020 沪深300  +  022430 中证A500         │
│  │            （002900 500信息作成长增强，≤管理仓 10%）     │
│  └─ 行业 40%（方案 B）：                                   │
│       ├─ 主卫星 25%：012737 创新药                         │
│       └─ 次席 15%：004253 黄金（防御分散）                 │
├─────────────────────────────────────────────────────────┤
│  定投旁路（不计入 60/40，不因涨跌调仓）                     │
│  └─ 270042 纳指日定投                                     │
└─────────────────────────────────────────────────────────┘
```

占比一律相对「管理仓」市值计算；旁路仓即使持仓，也不触发再平衡目标。

配置见 `satellite_sleeve`：`mode: dual`，主/次目标与候选、每月最多换行业 1 次、持有满 30 天再换、换出先回宽基。

### 为什么 002900 不算「主宽基」？

**002900** 跟踪的是 **中证500 里的「信息技术」子行业**，本质是**行业指数**，和人工智能、半导体高度相关：

- 比单押创新药**分散一些**  
- 但比 **沪深300 / A500** **窄得多**，波动仍偏大  
- 因此角色为 `core_growth`（成长增强），**上限 10%**，新增资金**优先买 110020 / 022430**

## 四、和支付宝操作的对应关系

| 你想做的事 | 买什么 | 改什么配置 |
|------------|--------|------------|
| 建核心、求稳 | 110020、022430 | 买入后写入 `positions.csv` |
| 略加科技暴露 | 002900（≤10%） | 已有可保留，不宜再加太多 |
| 主卫星（约 25%） | 012737 创新药 | `satellite_sleeve.primary_preferred` |
| 次席（约 15%） | **004253 黄金** | `satellite_sleeve.secondary_preferred` |
| 海外分散 | 270042 日定投 10 元 | 旁路，不计 60/40 |

**减仓主卫星后的钱** → 优先申购 **110020 + 022430**（各一半），次席黄金不足 15% 时可先补黄金。
若主卫星过重：减到约 25%，多余回宽基；次席黄金偏低则用减仓/新增资金补到约 15%。

## 六、常见问题

**Q：宽基会亏吗？**  
会。宽基只是**比行业基更分散**，不保证不跌；优势是长期持有、少踩单一行业雷。

**Q：为什么要两只宽基？**  
300 偏稳、A500 偏均衡成长，组合可降低「押错风格」的风险。

**Q：智能定投怎么用？**  
- **A 股宽基加仓**：参考沪深300 PE 分位（低估加倍、高估减半）  
- **阶梯补仓（DIP_BUY_CORE）**：指数自高点回撤 10%/20%/30% 且估值不过高时，用备用金分档补 110020/022430  
- **卫星补仓（DIP_BUY_SATELLITE）**：主卫星未超 25%、未进逻辑减仓档时，回撤/浮亏 12%/20%/28% 小额分档补；黄金只按 15% 目标结构性补缺  
- **270042 纳指**：固定 10 元/天，不跟 A 股估值走  

**Q：什么时候止损清仓？**  
宽基不做价格清仓。行业卫星浮亏约 −20% 复盘、−40%/−50% 可减仓回宽基（默认不清零）；须人工确认逻辑是否失效。次席黄金不做浮亏止损，按约 15% 仓位目标管理。与补仓冲突时：**减仓/逻辑退出优先于补仓**。
